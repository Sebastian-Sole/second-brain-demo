Friction is raw material, not knowledge

You asked whether corrections should end up in the cortex. They should. The part that shouldn't is a different artifact with the same name, and your vault already sorts these two correctly for a different kind of input.

The thing I said badly

"Log the corrections" is one phrase covering two objects with nothing in common except their origin.

Both live in the cortex. I said "outside the repo" last turn and that was wrong. cortex/raw/ is inside the cortex. What it is outside is the retrieval path, and that distinction is the one I failed to draw.

You already run this exact pipeline

ingest-sessions takes gigabytes of coding transcripts full of client code and credentials, keeps them in cortex/raw/sessions/transcripts/ where git cannot reach them, and writes short distilled notes into the vault proper. Friction is the same pipeline with a smaller input.

StageHomeWhy there

Distilled conclusionA spoke in cortex/03_Resources/ This is decision 6, which you already accepted. Friction is its missing input.

So 2 is not a new idea sitting beside 6. 2 is the raw end of the pipeline whose far end is 6. Without it, the spoke you agreed to build has nothing to be built from except whatever the model happens to remember noticing.

Two reasons the raw end stays out of search and git

Search. Your own argument, made about weather in digest: a note saying "12°C, rain from 14:00" is true for four hours and then competes with real notes in keyword search forever. A line saying shorter at 14:03 has exactly that shape.

Git. sync runs git add -A on the Stop hook after every turn. Your .gitignore already carries five entries written because of that, including one whose comment reads "a key pasted into 00_Inbox/ is a key on GitHub". A log of verbatim prompt text is the sixth entry or it is a public record of everything you typed.

The rule this brushes against, and you should settle it

A proposal may only come from something they said. Never from connector data, shell history, neighbouring repos, or which tools happen to be installed. AGENTS.md:159

A friction log holds the human's own typed words, so by the letter it passes: it is the purest possible case of "something they said". But the word said is doing unexamined work in that sentence. Today it quietly means "said in this session, still in context". A log extends it to "said, ever, and provably, with a timestamp".

The decision, and it is yours

The ban at AGENTS.md:302 exists because environment-derived profiling "reads as surveillance". A friction log is not environment data, but it is the first evidence class that lets the vault cite what you said weeks ago. Whether that is faithful memory or a record you did not know was being kept depends on one thing: whether the manual says out loud that it exists. Write the scope extension into AGENTS.md, or do not build it.

What a log line may hold

Three fields, and deliberately not a fourth.

  • The token. shorter, huh?, park it, decide:. Exact string equality on the four magic words your agreement already defines. No fuzzy matching, no model judgment, no false positives.
  • When. A timestamp, because the threshold in lesson 3 counts occurrences in a window.
  • A pointer. session_id, so a later pass can go and look at what was being shortened. The correction alone is uninterpretable a week later.
  • Not the answer text. Storing what the brain said is how a log becomes a transcript, and you already have a policy for transcripts.

Before you close this

Your friction log has 40 lines. None of them has ever been read by any command. Name the two things that are now true, one good and one bad.

Check yourself

Good: nothing has gone wrong. The log is inert by design. It is not in search, so it has not polluted a single answer, and it is not in git, so it has not leaked. An unread raw store costs nothing, which is exactly why cortex/raw/ is safe to write to.

Bad: you have built the observe step and none of the value. The log is evidence for a conclusion nobody drew. Until maintain or interview reads it and proposes something, the loop still ends where it ended before, and the demo shows a file instead of a change in behaviour.
