# Ideer

> [!callout icon=light-bulb] Én side per idé. Hver side sier hva friksjonen er, hva du får, hva du trenger, og gir deg prompten. Start med den som ligner mest på din egen hverdag.

Nivåene sier hvor mye du må koble til. En kobling er en tjeneste utenfor notatene: en nettside, kalenderen din, e-posten.

- **Enkel.** Ingenting å koble til. En prompt du kan bruke om igjen.

- **Middels.** Én kobling. Ingenting nytt å holde oppdatert.

- **Krevende.** Én kobling, og noe nytt assistenten må lære og holde styr på, som hva du liker eller hva du spiste.

- **Ekstra krevende.** Flere koblinger og flere nye ting å holde styr på.

Samme idé kan være Enkel eller Ekstra krevende. Det kommer an på hvor langt du tar den.
