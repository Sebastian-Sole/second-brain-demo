## Findings considered and rejected

Checked and found not to be problems. Recorded so they are not re-audited.

- **`brain/bin/sessions:50` and `:62`** — `case "$proj" in *"${pattern}"*) ;; *) [ -n "$pattern" ] && continue ;; esac` looks like an early exit under `set -e`. It is not: when `pattern` is empty, `*""*` always matches the first branch, so the `&&` never returns non-zero. Fragile but correct.
- **`brain/tools/location.md:2`** — the `ip-api.com` fallback runs over plain HTTP. That is the service's free tier, and the tool already discloses the third-party lookup. Not worth a change.
- **`brain/bin/check:232-237`** — the spoke list maps every wikilink in `About me.md` into the profile guard, including ordinary notes. This over-matches, so it errs toward being stricter than the rule requires. No action.
- **`AGENTS.md` tables versus the filesystem** — all 18 command wrappers resolve, all 5 tools declare the full five-field contract, the folder map matches `cortex/`, and the skills and tools tables match `brain/prompts/` and `brain/tools/`. No drift.
- **Secrets** — every tracked file was searched for private keys and provider tokens, and both presentation files for email addresses. Nothing found.
